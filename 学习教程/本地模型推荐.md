# 推荐本地模型清单

根据你的硬件和需求选择合适的模型。GGUF 格式通用性最好，Ollama、LM Studio、llama.cpp 都支持。

---

## 小模型（1.5B - 7B）

适合 8GB RAM 的笔记本，日常使用首选。

| 模型 | 参数 | 量化后大小 | 特点 |
|------|------|-----------|------|
| **Qwen2.5-7B-Instruct** | 7B | ~4.5GB (Q4) | 中英文最强通用模型，编程也强 |
| **Qwen2.5-Coder-7B** | 7B | ~4.5GB (Q4) | 专注代码生成和补全 |
| **Llama 3.2-3B** | 3B | ~2.5GB (Q4) | 轻量级英文模型，速度极快 |
| **Mistral 7B v0.3** | 7B | ~4.5GB (Q4) | 英文通用能力强 |
| **Phi-3.5-mini** | 3.8B | ~3GB (Q4) | 微软出品，小而精 |
| **DeepSeek-Coder-V2-Lite** | 16B | ~10GB (Q4) | 编程特化，但需要更多内存 |
| **Gemma 2-2B/9B** | 2B/9B | ~1.5GB/~6GB | Google 出品，英文好 |

> 8GB 内存 → 首选 7B Q4_K_M
> 16GB 内存 → 可跑 7B Q8_0 或 14B Q4_K_M

## 中等模型（8B - 14B）

需要 16GB+ RAM，效果明显提升。

| 模型 | 参数 | 量化后大小 | 特点 |
|------|------|-----------|------|
| **Qwen2.5-14B-Instruct** | 14B | ~9GB (Q4) | 接近 GPT-3.5 水平 |
| **Llama 3.1-8B** | 8B | ~5.5GB (Q4) | Meta 最新，英文强 |
| **DeepSeek-R1-Distill-Qwen-7B** | 7B | ~4.5GB (Q4) | 带思维链的推理模型 |
| **DeepSeek-R1-Distill-Llama-8B** | 8B | ~5.5GB (Q4) | 推理+通用结合 |
| **Mistral Nemo** | 12B | ~8GB (Q4) | Mistral 与英伟达合作 |

## 大模型（30B - 72B）

需要 32GB+ RAM 或 GPU，效果接近 GPT-4。

| 模型 | 参数 | 量化后大小 | 特点 |
|------|------|-----------|------|
| **Qwen2.5-32B-Instruct** | 32B | ~19GB (Q4) | 本地最强中文模型之一 |
| **Qwen2.5-72B-Instruct** | 72B | ~42GB (Q4) | 接近 GPT-4 级别 |
| **DeepSeek-R1-Distill-Qwen-32B** | 32B | ~19GB (Q4) | 推理能力极强 |
| **Llama 3.1-70B** | 70B | ~41GB (Q4) | 英文旗舰模型 |
| **Mistral Large** | 123B | ~70GB (Q4) | 超大模型，需高配置 |

## 量化选择指南

```
内存充裕 → Q8_0 或 Q6_K（质量优先）
内存适中 → Q4_K_M（推荐，平衡之选）
内存紧张 → Q3_K_M 或 Q2_K（能用就行）
```

| 量化 | 相对质量 | 7B 模型大小 |
|------|---------|-----------|
| Q2_K | ~60% | ~3GB |
| Q3_K_M | ~75% | ~4GB |
| **Q4_K_M** | **~90%** | **~4.5GB** |
| Q5_K_M | ~95% | ~5.5GB |
| Q6_K | ~98% | ~6.5GB |
| Q8_0 | ~99.5% | ~7GB |
| F16 | 100% | ~14GB |

## 场景推荐

| 场景 | 首选模型 | 备选 |
|------|---------|------|
| **编程** | Qwen2.5-Coder-7B | DeepSeek-Coder-V2-Lite |
| **中文对话** | Qwen2.5-7B / 14B | DeepSeek-R1-Distill-Qwen |
| **英文对话** | Llama 3.1-8B | Mistral 7B |

| **极低配置** | Llama 3.2-3B | Phi-3.5-mini |

## 获取模型的地方

- **Ollama 直接拉**：`ollama pull qwen2.5` 最方便
- **Hugging Face**：搜索 `GGUF` 关键词，选星星多的
- **Modelscope**：国内镜像，下载速度快
- **LM Studio**：应用内直接搜索下载

## 一句话建议

- 不确定选什么 → **Qwen2.5-7B-Instruct (Q4_K_M)**
- 只有 8GB 内存 → **Qwen2.5-7B-Instruct (Q4_K_M)**
- 有 16GB 内存 → **Qwen2.5-14B-Instruct (Q4_K_M)** 或 **DeepSeek-R1-Distill-Qwen-7B**
- 有 32GB+ → **Qwen2.5-32B-Instruct (Q4_K_M)**
- 全是英文场景 → **Llama 3.1-8B** 或 **Mistral 7B**
