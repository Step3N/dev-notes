# [链路] 终端美化增强

> 一条路打通三平台终端美化，从字体到提示符再到效率插件

**适用平台**：macOS / Windows / Linux
**预估耗时**：20-30 分钟
**前置条件**：
- 有终端基础
- macOS 用户已装 Homebrew，Windows 用户已装 winget

---

## Step 1: 安装 Nerd Font

Nerd Font 提供图标和 Powerline 符号，是终端美化的基石。

### macOS
```bash
brew install --cask font-jetbrains-mono-nerd-font
```

### Windows
```powershell
oh-my-posh font install jetbrains-mono
```

### Linux
```bash
wget https://github.com/ryanoasis/nerd-fonts/releases/latest/download/JetBrainsMono.zip
mkdir -p ~/.local/share/fonts
unzip -o JetBrainsMono.zip -d ~/.local/share/fonts/
fc-cache -fv && rm JetBrainsMono.zip
```

### 验证
```bash
fc-list | grep -i JetBrainsMono
```
预期输出：`JetBrainsMonoNerdFont-Regular.ttf: JetBrainsMono Nerd Font`

> 📖 详见：[Linux 终端美化](../配置调优/linux-终端美化.md)

## Step 2: 配置终端模拟器

安装字体后必须在终端中选中它。

### macOS — iTerm2
```bash
brew install --cask iterm2
```
`Cmd+,` → Profiles → Text → Font → **JetBrainsMono Nerd Font**（字号 14）

> 📖 详见：[iTerm2](../配置调优/iterm2.md)

### Windows — Windows Terminal
```powershell
winget install Microsoft.WindowsTerminal
```
`Ctrl+,` → 打开 settings.json：
```json
{ "profiles": { "defaults": { "font": { "face": "JetBrainsMono Nerd Font", "size": 12 } } } }
```

> 📖 详见：[Windows Terminal](../配置调优/windows-terminal.md)

### Linux — Kitty
```bash
sudo apt install kitty -y
```
`~/.config/kitty/kitty.conf`：
```conf
font_family JetBrainsMono Nerd Font
font_size 13
```

> 📖 详见：[Linux 终端美化](../配置调优/linux-终端美化.md)

## Step 3: 安装 Shell + 框架

### macOS / Linux — Oh My Zsh
```bash
# Linux 先装 Zsh（macOS 自带）
sudo apt install zsh -y
# 安装 Oh My Zsh
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

### Windows — Oh My Posh
```powershell
winget install JanDeDobbeleer.OhMyPosh
if (!(Test-Path $PROFILE)) { New-Item $PROFILE -Force }
'oh-my-posh init pwsh --config "$env:POSH_THEMES_PATH\jandedobbeleer.omp.json" | Invoke-Expression' >> $PROFILE
. $PROFILE
```

> 📖 详见：[Oh My Zsh](../配置调优/oh-my-zsh.md) / [Oh My Posh](../配置调优/oh-my-posh.md)

## Step 4: 配置 Prompt

### 方案 A：Powerlevel10k（macOS / Linux）
```bash
git clone --depth=1 https://github.com/romkatv/powerlevel10k.git ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/themes/powerlevel10k
sed -i 's/ZSH_THEME=".*"/ZSH_THEME="powerlevel10k\/powerlevel10k"/' ~/.zshrc
# 重启终端后运行配置向导
p10k configure
```

### 方案 B：Starship（跨平台，推荐新手）
```bash
curl -sS https://starship.rs/install.sh | sh
```
添加到 shell 配置末尾：
```bash
# ~/.zshrc
echo 'eval "$(starship init zsh)"' >> ~/.zshrc
```
```powershell
# $PROFILE
echo "invoke-expression (&starship init powershell)" >> $PROFILE
```
应用预设：
```bash
starship preset nerd-font-symbols -o ~/.config/starship.toml
```

> 📖 详见：[Starship](../配置调优/starship.md)

## Step 5: 实用插件

### Zsh 插件（macOS / Linux）
```bash
git clone https://github.com/zsh-users/zsh-autosuggestions ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions
git clone https://github.com/zsh-users/zsh-syntax-highlighting ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting
```
编辑 `~/.zshrc`，将 `plugins=(git)` 替换为：
```bash
plugins=(git zsh-autosuggestions zsh-syntax-highlighting web-search docker npm extract sudo colored-man-pages)
source ~/.zshrc
```

### PowerShell 增强（Windows）
```powershell
Install-Module PSReadLine -Force -SkipPublisherCheck
@"
Set-PSReadLineOption -PredictionSource History
Set-PSReadLineOption -PredictionViewStyle ListView
"@ >> $PROFILE
. $PROFILE
```

### fzf — 模糊搜索（所有平台）
```bash
# macOS
brew install fzf && $(brew --prefix)/opt/fzf/install
# Linux
git clone --depth 1 https://github.com/junegunn/fzf.git ~/.fzf && ~/.fzf/install
# Windows
scoop install fzf
```
使用：`Ctrl+R` 搜历史，`Ctrl+T` 搜文件。

### zoxide — 智能 cd（所有平台）
```bash
curl -sS https://raw.githubusercontent.com/ajeetdsouza/zoxide/main/install.sh | sh
```
```bash
# ~/.zshrc
echo 'eval "$(zoxide init zsh)"' >> ~/.zshrc
```
```powershell
# $PROFILE
echo "zoxide init powershell | Invoke-Expression" >> $PROFILE
```
使用：先 `cd ~/Documents/MyProject`，之后只需 `z MyProject`。

> 📖 详见：[现代 CLI 工具](../日常使用/现代CLI工具.md)

## 最终验证

新开终端逐项检查：

```bash
# 1. Nerd Font 图标
echo -e "\uf0e7 \ue0b0 \ue0a0 \uf0c8"
# 2. Git 分支显示
mkdir -p /tmp/test-repo && cd /tmp/test-repo && git init
# 3. 自动建议：输入 cd /tmp，应有灰色建议
# 4. fzf：Ctrl+R 打开历史搜索
# 5. zoxide：z test-repo 跳回
```

| 检查项 | 操作 | 预期 |
|--------|------|------|
| Nerd Font | 执行 echo | 显示图标，无方框 |
| Prompt | 查看终端 | 显示 Git 分支、路径 |
| 自动建议 | 输入历史命令 | 灰色建议文字 |
| 语法高亮 | 输入 `git status` | 关键字着色 |
| fzf | `Ctrl+R` / `Ctrl+T` | 弹出搜索界面 |
| zoxide | `z <dir>` | 快速跳转 |

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 图标显示方框 □ | Nerd Font 未安装或未在终端字体设置中选择 |
| Powerlevel10k 乱码 | 运行 `p10k configure` 重新配置 |
| Oh My Zsh 启动慢 | 减少 plugins 数量 |
| Windows Terminal 设置不生效 | 检查 settings.json 语法 |
| Starship 不生效 | 确认 init 命令在 shell 配置的最后一行 |
| Oh My Posh 缺图标 | 确认终端字体已设为 Nerd Font |
| fzf Ctrl+R 无响应 | 确认 `.fzf.zsh` 已被 source |
