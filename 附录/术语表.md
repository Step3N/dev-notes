# 术语表

常见技术术语 A-Z 速查，用大白话解释每个概念。

> 全平台通用。

---

## 📦 版本控制

| 术语 | 英文 | 解释 |
|------|------|------|
| 仓库 | Repository | 存放代码和版本历史的地方，就像一个项目的「文件夹+时光机」 |
| 提交 | Commit | 保存当前代码快照，生成一个唯一的版本号 |
| 分支 | Branch | 从主线分离出来的独立开发线，互不干扰 |
| 合并 | Merge | 把一个分支的改动合并到另一个分支 |
| 变基 | Rebase | 把当前分支的提交「移植」到另一个分支顶部，历史更干净 |
| HEAD | HEAD | 指向当前所在分支最新提交的指针 |
| 暂存区 | Staging Area | 提交前的「候车区」，可以决定哪些改动进入下一次提交 |
| 远程 | Remote | 托管在服务器上的仓库副本（如 GitHub） |
| 获取 | Fetch | 从远程下载最新数据但不合并 |
| 拉取请求 | Pull Request | 通知项目维护者「我写好了一个功能，请合并」 |
| 复刻 | Fork | 在 GitHub 上复制别人的仓库到自己的账号下 |
| 克隆 | Clone | 把远程仓库完整下载到本地 |

## 🐳 容器 / DevOps

| 术语 | 英文 | 解释 |
|------|------|------|
| 容器 | Container | 轻量级的虚拟化运行环境，隔离应用及其依赖 |
| 镜像 | Image | 容器的「模板」或「快照」，可用来创建多个相同的容器 |
| 卷 | Volume | 容器内持久化存储数据的方式，容器删除后数据还在 |
| Dockerfile | Dockerfile | 描述如何构建 Docker 镜像的脚本文件 |
| 编排 | Orchestration | 自动管理多个容器的部署、扩缩容、网络（如 Kubernetes） |
| CI/CD | CI/CD | 持续集成 + 持续交付，代码提交后自动构建、测试、部署 |
| 部署 | Deployment | 将应用发布到服务器上运行 |
| 流水线 | Pipeline | CI/CD 中自动化运行的各阶段任务（构建→测试→部署） |
| 制品 | Artifact | 构建产出的文件，如 `.jar`、`.whl`、Docker 镜像 |
| 仓库（镜像仓库） | Registry | 存储和分发容器镜像的服务（如 Docker Hub） |

## 🌐 网络

| 术语 | 英文 | 解释 |
|------|------|------|
| 代理 | Proxy | 中间服务器，帮你转发请求（翻墙 / 加速 / 负载均衡） |
| DNS | DNS | 把 `google.com` 翻译成 IP 地址的电话簿系统 |
| HTTP/HTTPS | HTTP/HTTPS | 浏览器和服务器通信的协议，HTTPS 加了加密 |
| SSL/TLS | SSL/TLS | 为网络通信提供加密和身份验证的安全协议 |
| SSH | SSH | 安全地远程登录服务器的加密协议 |
| TCP/IP | TCP/IP | 互联网的基础通信协议族 |
| 套接字 | Socket | 网络通信的端点，IP + 端口组成 |
| 端口 | Port | 应用在服务器上的门牌号（0-65535） |
| 防火墙 | Firewall | 按规则允许或阻止网络流量进出的安全工具 |
| CIDR | CIDR | IP 地址段表示法，如 `192.168.1.0/24` 表示 256 个地址 |
| VPN | VPN | 在公共网络上建立加密隧道，就像连入一个私有网络 |

## 💻 编程

| 术语 | 英文 | 解释 |
|------|------|------|
| 集成开发环境 | IDE | 集编辑器、调试器、终端于一体的软件开发工具 |
| SDK | SDK | 开发某平台/服务的工具包，含库、文档、示例 |
| API | API | 程序与程序之间的接口规范 |
| CLI | CLI | 命令行界面，在终端里输入命令操作 |
| GUI | GUI | 图形用户界面，用鼠标点击操作 |
| 二进制文件 | Binary | 编译后的可执行程序（非人类可读） |
| 库 | Library | 可复用的代码集合，供程序调用 |
| 框架 | Framework | 一套「骨架」代码，约束你写代码的方式 |
| 依赖 | Dependency | 项目运行时依赖的外部库或包 |
| 运行时 | Runtime | 程序运行所需的底层环境（如 Node.js 是 JS 的运行时） |
| 解释器 | Interpreter | 逐行读取并执行代码的程序（如 Python） |
| 编译器 | Compiler | 把高级语言整个翻译成机器码的工具（如 GCC） |

## 🤖 AI / 机器学习

| 术语 | 英文 | 解释 |
|------|------|------|
| 大语言模型 | LLM | 大型神经网络模型，能理解和生成自然语言 |
| 词元 | Token | 模型处理文本的最小单位，一个词或一个字 |
| 提示词 | Prompt | 给 AI 的输入文本，用来引导它生成想要的输出 |
| 微调 | Fine-tuning | 在预训练模型基础上用少量数据继续训练，适配特定任务 |
| RAG | Retrieval-Augmented Generation | 检索增强生成，让 AI 先查资料再回答问题 |
| 向量数据库 | Vector Database | 存储高维向量的数据库，用于语义搜索和相似度匹配 |
| 嵌入 | Embedding | 把文本/图片编码成数值向量，用于计算相似度 |
| 推理 | Inference | 模型根据输入生成输出的过程（跑一次预测） |
| 训练 | Training | 用大量数据调整模型参数，让它学会某个任务 |
| 模型 | Model | 训练好的神经网络参数文件，可被加载用于推理 |
| 量化 | Quantization | 压缩模型大小和加快速度的技术（如从 FP16 降为 INT4） |

## ⚙️ 系统

| 术语 | 英文 | 解释 |
|------|------|------|
| 内核 | Kernel | 操作系统的核心，管理硬件、进程、内存 |
| Shell | Shell | 接收并执行命令的命令行解释器（如 bash、zsh） |
| 守护进程 | Daemon | 后台持续运行的服务进程（如 nginx、sshd） |
| 进程 | Process | 正在运行的程序实例，有独立的内存空间 |
| 线程 | Thread | 进程内的轻量级执行单元，共享进程的内存 |
| 文件描述符 | File Descriptor | 内核用来追踪已打开文件的数字标识 |
| 符号链接 | Symlink | 指向另一个文件或目录的「快捷方式」 |
| 环境变量 | Environment Variable | 操作系统级别的键值对，影响程序行为 |
| PATH | PATH | 系统搜索可执行文件的目录列表（以 `:` 分隔） |
| 文件系统 | Filesystem | 管理文件和目录在磁盘上存储的方式（如 ext4、NTFS、APFS） |
