# 常用镜像源汇总

国内访问官方软件源速度慢，换镜像加速是开发必备技能。本文汇总主流包管理器的镜像配置方法。

> 全平台通用。

---

## 📦 pip (Python)

| 镜像源 | 地址 |
|--------|------|
| 清华 (TUNA) | `https://pypi.tuna.tsinghua.edu.cn/simple` |
| 阿里云 | `https://mirrors.aliyun.com/pypi/simple` |
| 中科大 (USTC) | `https://pypi.mirrors.ustc.edu.cn/simple` |
| 华为云 | `https://mirrors.huaweicloud.com/repository/pypi/simple` |
| 豆瓣 | `https://pypi.doubanio.com/simple` |

```bash
# 配置（全局）
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

# 恢复官方源
pip config unset global.index-url
```

## 📦 npm / Node.js

| 镜像源 | 地址 |
|--------|------|
| 淘宝 (npmmirror) | `https://registry.npmmirror.com` |
| 华为云 | `https://mirrors.huaweicloud.com/repository/npm` |
| 腾讯云 | `https://mirrors.cloud.tencent.com/npm` |
| 中科大 | `https://npmreg.mirrors.ustc.edu.cn` |

```bash
# 配置
npm config set registry https://registry.npmmirror.com

# 恢复官方源
npm config set registry https://registry.npmjs.org

# 查看当前源
npm config get registry
```

项目级配置（推荐）：在项目根目录创建 `.npmrc`：

```
registry=https://registry.npmmirror.com
```

## 🐳 Docker

在 `/etc/docker/daemon.json` 中配置 `registry-mirrors`：

```json
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://dockerhub.timeweb.cloud",
    "https://dockerproxy.com"
  ]
}
```

| 镜像源 | 地址 |
|--------|------|
| DaoCloud | `https://docker.m.daocloud.io` |
| 南京大学 | `https://docker.nju.edu.cn` |
| 中科大 | `https://docker.mirrors.ustc.edu.cn` |
| 阿里云 | `https://<你的ID>.mirror.aliyuncs.com`（需登录获取） |

配置后重启 Docker：

```bash
sudo systemctl restart docker   # Linux
# macOS: 点菜单栏 Docker → Preferences → Docker Engine 粘贴
```

恢复官方：删除或注释 `registry-mirrors` 字段，重启 Docker。

## 🍺 Homebrew

| 镜像源 | 说明 |
|--------|------|
| 中科大 | 推荐，稳定 |
| 清华 | 备用 |

使用中科大镜像：

```bash
# 设置环境变量
export HOMEBREW_API_DOMAIN="https://mirrors.ustc.edu.cn/homebrew-bottles/api"
export HOMEBREW_BREW_GIT_REMOTE="https://mirrors.ustc.edu.cn/brew.git"
export HOMEBREW_CORE_GIT_REMOTE="https://mirrors.ustc.edu.cn/homebrew-core.git"
export HOMEBREW_BOTTLE_DOMAIN="https://mirrors.ustc.edu.cn/homebrew-bottles"
```

持久化配置（写入 `~/.zshrc` 或 `~/.bashrc`）：

```bash
echo 'export HOMEBREW_API_DOMAIN="https://mirrors.ustc.edu.cn/homebrew-bottles/api"' >> ~/.zshrc
echo 'export HOMEBREW_BREW_GIT_REMOTE="https://mirrors.ustc.edu.cn/brew.git"' >> ~/.zshrc
echo 'export HOMEBREW_CORE_GIT_REMOTE="https://mirrors.ustc.edu.cn/homebrew-core.git"' >> ~/.zshrc
echo 'export HOMEBREW_BOTTLE_DOMAIN="https://mirrors.ustc.edu.cn/homebrew-bottles"' >> ~/.zshrc
```

恢复官方：取消这些环境变量即可。

## 📦 apt (Debian/Ubuntu)

替换 `/etc/apt/sources.list`。以 Ubuntu 22.04 (jammy) 清华源为例：

```bash
# 备份
sudo cp /etc/apt/sources.list /etc/apt/sources.list.bak

# 替换为清华源
sudo sed -i 's|http://archive.ubuntu.com/ubuntu|https://mirrors.tuna.tsinghua.edu.cn/ubuntu|g' /etc/apt/sources.list
sudo sed -i 's|http://security.ubuntu.com/ubuntu|https://mirrors.tuna.tsinghua.edu.cn/ubuntu|g' /etc/apt/sources.list

# 更新
sudo apt update
```

恢复官方：

```bash
sudo cp /etc/apt/sources.list.bak /etc/apt/sources.list
sudo apt update
```

> `jammy` 对应 Ubuntu 22.04，其他版本需替换。查看版本：`lsb_release -c`

## 📦 Maven / Gradle

### Maven

在 `~/.m2/settings.xml` 中添加：

```xml
<mirrors>
  <mirror>
    <id>aliyun</id>
    <name>Aliyun Maven Mirror</name>
    <url>https://maven.aliyun.com/repository/public</url>
    <mirrorOf>central</mirrorOf>
  </mirror>
</mirrors>
```

| 镜像源 | 地址 |
|--------|------|
| 阿里云 | `https://maven.aliyun.com/repository/public` |
| 华为云 | `https://mirrors.huaweicloud.com/repository/maven` |

### Gradle

在 `build.gradle` 或 `init.gradle` 中：

```groovy
repositories {
    maven { url 'https://maven.aliyun.com/repository/public' }
    mavenCentral()
}
```
