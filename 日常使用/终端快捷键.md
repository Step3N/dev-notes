# 常用终端快捷键

> **平台**：全平台（区分 macOS 与 Windows/Linux）

## 标签/窗口管理

| 操作 | **macOS (iTerm2/Terminal)** | **Windows Terminal** | **Linux (GNOME/Konsole)** |
|------|----------------------------|---------------------|--------------------------|
| 新建标签 | `⌘T` | `Ctrl+Shift+T` | `Ctrl+Shift+T` |
| 关闭标签 | `⌘W` | `Ctrl+Shift+W` | `Ctrl+Shift+W` |
| 上一个标签 | `⌘⇧[` | `Ctrl+Shift+Tab` | `Ctrl+PageUp` |
| 下一个标签 | `⌘⇧]` | `Ctrl+Tab` | `Ctrl+PageDown` |
| 跳转到第 N 标签 | `⌘1` ~ `⌘9` | `Alt+1` ~ `Alt+9` | `Alt+1` ~ `Alt+9` |
| 垂直分屏 | `⌘D` | `Alt+Shift+D` | `Ctrl+Shift+` 或右键 |
| 水平分屏 | `⌘⇧D` | `Alt+Shift+-` | `Ctrl+Shift+` 或右键 |
| 切换分屏 | `⌘]` / `⌘[` | `Alt+方向键` | `Ctrl+Tab` |

## 进程控制

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 中断进程 | `Ctrl+C` | 发送 SIGINT，终止当前进程 |
| 结束输入 | `Ctrl+D` | 发送 EOF，退出 shell 或输入结束 |
| 暂停进程 | `Ctrl+Z` | 发送 SIGTSTP，挂起到后台（`fg` 恢复） |
| 清屏 | `Ctrl+L` | 清空屏幕（等效于 `clear` 命令） |

```bash
# 验证：Ctrl+C 中断一个卡住的命令
ping 127.0.0.1
# 按 Ctrl+C 终止

# 验证：Ctrl+Z 挂起后恢复
sleep 100
# 按 Ctrl+Z
[1]+  Stopped
fg      # 恢复前台
```

## 行内导航

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 跳到行首 | `Ctrl+A` | 等效 `Home` |
| 跳到行尾 | `Ctrl+E` | 等效 `End` |
| 前删到行首 | `Ctrl+U` | 剪切光标前所有内容 |
| 后删到行尾 | `Ctrl+K` | 剪切光标后所有内容 |
| 删除前一个单词 | `Ctrl+W` | 以空格/符号分隔 |
| 删除后一个单词 | `Alt+D` | 仅 **macOS** 需配置 Option 为 Meta |
| 撤销上一步 | `Ctrl+Y` | 粘贴刚才 `Ctrl+U/K/W` 剪切的内容 |
| 交换字符 | `Ctrl+T` | 交换光标前两个字符 |

**macOS 注意**：要使用 `Alt` 快捷键，在 iTerm2 中需设置：
```
Preferences → Profiles → Keys → Left Option Key → Esc+
```

## 历史与搜索

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 上一条命令 | `↑` / `Ctrl+P` | 向前翻阅历史 |
| 下一条命令 | `↓` / `Ctrl+N` | 向后翻阅历史 |
| 搜索历史 | `Ctrl+R` | 反向增量搜索（配合 `fzf` 效果更好） |
| 继续搜索 | `Ctrl+R` 再按 | 循环上一个匹配 |
| 退出搜索 | `Ctrl+G` / `Esc` | 取消搜索 |
| 搜索终端输出 | `Ctrl+Shift+F` | **Windows Terminal** / iTerm2 原生搜索 |

```bash
# 验证 Ctrl+R
# 按 Ctrl+R，输入 "git"，会匹配最近的 git 命令
# 再按 Ctrl+R 跳到上一条匹配
```

## 文本选择与复制（macOS iTerm2）

| 快捷键 | 操作 |
|--------|------|
| `⌘A` | 全选 |
| `⌘C` | 复制选中内容 |
| `⌘V` | 粘贴 |
| `⌘⇧V` | 粘贴转义文本（无格式） |

## 常用特殊键

| 快捷键 | 说明 |
|--------|------|
| `Tab` | 自动补全命令/路径/参数 |
| `Tab` + `Tab` | 显示所有补全候选 |
| `Ctrl+Shift+C` | **Windows Terminal / Linux** 复制 |
| `Ctrl+Shift+V` | **Windows Terminal / Linux** 粘贴 |

## 缩放

| 操作 | **macOS** | **Windows/Linux** |
|------|-----------|-------------------|
| 放大 | `⌘+` / `⌘=` | `Ctrl+Shift+=` |
| 缩小 | `⌘-` | `Ctrl+Shift+-` |
| 重置缩放 | `⌘0` | `Ctrl+0` |

## 杂项

| 命令/快捷键 | 说明 |
|-------------|------|
| `reset` | 重置终端（乱码时用：`cat` 二进制文件后终端花屏） |
| `clear` 或 `Ctrl+L` | 清屏但不清除回滚缓冲区 |
| `exit` 或 `Ctrl+D` | 退出当前 shell |

```bash
# 终端乱码时执行
reset
```

## tmux 快捷键（tmux 用户）

| 前缀 | 快捷键 | 操作 |
|------|--------|------|
| `Ctrl+B` | `c` | 创建新窗口 |
| `Ctrl+B` | `,` | 重命名窗口 |
| `Ctrl+B` | `n` / `p` | 下一个/上一个窗口 |
| `Ctrl+B` | `%` | 垂直分屏 |
| `Ctrl+B` | `"` | 水平分屏 |
| `Ctrl+B` | `方向键` | 切换分屏 |
| `Ctrl+B` | `d` | 分离会话 |
| `Ctrl+B` | `[` | 进入滚动模式（`PgUp/PgDn` 翻页，`q` 退出） |

```bash
# 验证 tmux
tmux new -s test
# 在 tmux 中按 Ctrl+B c 创建新窗口
# 按 Ctrl+B d 分离
tmux attach -t test   # 重新连接
tmux kill-session -t test  # 删除会话
```
