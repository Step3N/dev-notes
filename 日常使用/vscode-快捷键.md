# VS Code 常用快捷键

全平台通用。macOS 用 `⌘`，Windows/Linux 用 `Ctrl`。

---

## 通用

| 操作 | macOS | Windows / Linux |
|------|-------|----------------|
| 命令面板 | `⌘⇧P` | `Ctrl+Shift+P` |
| 快速打开文件 | `⌘P` | `Ctrl+P` |
| 切换侧边栏 | `⌘B` | `Ctrl+B` |
| 设置 | `⌘,` | `Ctrl+,` |
| 键盘快捷方式 | `⌘K ⌘S` | `Ctrl+K Ctrl+S` |
| 全屏 | `⌘Ctrl+F` | `F11` |

---

## 编辑器操作

| 操作 | macOS | Windows / Linux |
|------|-------|----------------|
| 多光标 — 选中下一个相同词 | `⌘D` | `Ctrl+D` |
| 多光标 — 全部选中 | `⌘⇧L` | `Ctrl+Shift+L` |
| 多光标 — 添加额外光标 | `⌥+click` | `Alt+Click` |
| 移动当前行 | `⌥↑` / `⌥↓` | `Alt+↑` / `Alt+↓` |
| 复制当前行 | `⌥⇧↑` / `⌥⇧↓` | `Alt+Shift+↑` / `Alt+Shift+↓` |
| 删除当前行 | `⌘⇧K` | `Ctrl+Shift+K` |
| 注释 / 取消注释 | `⌘/` | `Ctrl+/` |
| 块注释 | `⌥⇧A` | `Shift+Alt+A` |
| 缩进 / 取消缩进 | `⌘]` / `⌘[` | `Ctrl+]` / `Ctrl+[` |
| 格式化文档 | `⇧⌥F` | `Shift+Alt+F` |
| 格式化选区 | `⌘K ⌘F` | `Ctrl+K Ctrl+F` |
| 代码折叠 / 展开 | `⌘⌥[` / `⌘⌥]` | `Ctrl+Shift+[` / `Ctrl+Shift+]` |

## 自定义快捷键

打开键盘快捷方式文件：`⌘K ⌘S`（macOS）/ `Ctrl+K Ctrl+S`（Windows/Linux）

或在命令面板中搜索 `Preferences: Open Keyboard Shortcuts (JSON)`。
