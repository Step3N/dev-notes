# 通义灵码 (TONGYI Lingma)

阿里云推出的免费 AI 编程助手，基于通义千问 Qwen 模型。

---

## 基本信息

| 项目 | 说明 |
|------|------|
| 价格 | 完全免费 |
| 模型 | 通义千问 Qwen |
| 发布方 | Alibaba Cloud |
| 网站 | https://tongyi.aliyun.com/lingma/ |

---

## 安装

### VS Code

1. 扩展市场搜索 `TONGYI Lingma`
2. 安装后点击状态栏图标登录
3. 支持阿里云账号或淘宝账号登录

### JetBrains

1. Preferences → Plugins → 搜索 `TONGYI Lingma`
2. 安装后重启
3. 配置 Tools → TONGYI Lingma 中的登录

### 其他

目前主要支持 VS Code 和 JetBrains，不覆盖 Neovim 或 Xcode。

## 功能

### 代码补全

行级和块级补全，自动触发。

```python
# 输入后自动补全
def sort_users_by_date(users):
    # 灵码会自动建议排序实现
    return sorted(users, key=lambda u: u['created_at'], reverse=True)
```

### 对话 Chat

侧边栏对话，支持 @workspace 等上下文。可以用中文自然交流。

### 单元测试生成

右键代码 → TONGYI Lingma → 生成测试，自动生成 pytest/unittest 测试用例。

### 代码解释

选中代码，右键 → 解释代码。适合快速理解不熟悉的代码。

### 代码优化

选中代码，右键 → 优化建议，给出性能和安全方面的改进建议。

## 中文支持

通义灵码对中文的天然支持是其最大优势：

- **中文注释理解**：可以用中文写注释，补全质量高
- **中文对话**：Chat 里用中文提问，理解准确
- **中文命名**：支持中文变量名、函数名（虽然不推荐）

```python
# 用中文注释，灵码补全最准
# 计算用户本月活跃天数
def calculate_monthly_active_days(user_id):
    # 灵码能准确理解这个业务逻辑
    pass
```

## 优缺点

### 优点
- 完全免费，无使用次数限制
- 中文理解最佳，适合中国开发者
- Java 生态优化好（国内 Java 项目多）
- 阿里云账号即可使用，门槛低

### 缺点
- 补全质量不如 Copilot 和 Cursor
- 只支持 VS Code 和 JetBrains
- 国际知名度低，社区小
- 复杂重构场景能力弱
- 模型更新速度不如 OpenAI

## 在 Java 项目中的表现

通义灵码对 Java 做了专项优化，在阿里系技术栈（Spring Boot、Dubbo、MyBatis）中表现不错：

```java
// 灵码能自动补全 Service 层代码
@Service
public class UserServiceImpl implements UserService {
    @Override
    public Result<UserVO> getUserInfo(Long userId) {
        // 输入注释后灵码补全
        // 1. 校验参数
        // 2. 查询用户
        // 3. 转换 VO
        // 4. 返回结果
    }
}
```
