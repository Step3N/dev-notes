# 国产大模型 API 笔记

国内多家厂商提供 LLM API，兼容性各不相同。部分完全兼容 OpenAI 格式，切换成本极低。

---

## 通义千问 (Qwen) — 阿里云 DashScope

完全兼容 OpenAI SDK，只需改 `base_url` 和 `api_key`。

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_DASHSCOPE_API_KEY",    # 替换为你的 key
    base_url="https://dashscope.aliyuncs.com/compatible-mode/v1"
)

response = client.chat.completions.create(
    model="qwen-plus",          # qwen-turbo / qwen-plus / qwen-max
    messages=[{"role": "user", "content": "你好"}]
)
print(response.choices[0].message.content)
```

| 模型 | 说明 | 上下文 |
|------|------|--------|
| qwen-turbo | 轻量快速 | 1M |
| qwen-plus | 均衡，推荐日常使用 | 1M |
| qwen-max | 最强 | 32K |

> 注册: https://dashscope.aliyun.com/ 获取 API Key 后开通模型服务。

## 智谱 (GLM) — ZhipuAI

使用独立 SDK，格式与 OpenAI 类似。

```bash
pip install zhipuai
```

```python
from zhipuai import ZhipuAI

client = ZhipuAI(api_key="YOUR_ZHIPU_API_KEY")  # 替换为你的 key

response = client.chat.completions.create(
    model="glm-4",               # glm-4 / glm-4v (视觉) / glm-4-plus
    messages=[{"role": "user", "content": "你好"}]
)
print(response.choices[0].message.content)
```

| 模型 | 说明 | 上下文 |
|------|------|--------|
| glm-4-plus | 增强版 | 128K |
| glm-4 | 标准版 | 128K |
| glm-4v | 支持图片 | 128K |

> 智谱也提供 OpenAI 兼容接口：`https://open.bigmodel.cn/api/paas/v4`

## 文心一言 (ERNIE) — 百度

使用独立的 access_token 认证机制。

```bash
# 获取 access_token（有效期 30 天）
curl 'https://aip.baidubce.com/oauth/2.0/token?grant_type=client_credentials&client_id=YOUR_API_KEY&client_secret=YOUR_SECRET_KEY'
```

```python
import requests

API_URL = "https://aip.baidubce.com/rpc/2.0/ai_custom/v1/wenxinworkshop/chat/completions_pro"
ACCESS_TOKEN = "your_access_token"

response = requests.post(
    f"{API_URL}?access_token={ACCESS_TOKEN}",
    json={"messages": [{"role": "user", "content": "你好"}]}
)
print(response.json())
```

| 模型 | 说明 |
|------|------|
| ERNIE-4.0 | 最强 |
| ERNIE-3.5 | 性价比之选 |
| ERNIE Speed | 轻量快速 |

> 百度控制台: https://console.bce.baidu.com/qianfan/ 申请 API Key。

## DeepSeek

完全兼容 OpenAI 格式，切换成本为零。

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_DEEPSEEK_API_KEY",     # 替换为你的 key
    base_url="https://api.deepseek.com"
)

response = client.chat.completions.create(
    model="deepseek-chat",       # deepseek-chat / deepseek-reasoner
    messages=[{"role": "user", "content": "你好"}]
)
```

| 模型 | 说明 | 上下文 |
|------|------|--------|
| deepseek-chat | 通用对话 | 64K |
| deepseek-reasoner | 推理模型（类似 o1） | 64K |

> deepseek-reasoner 输出思考过程在 `response.choices[0].message.reasoning_content`。

## 兼容性对比

| 厂商 | OpenAI 兼容 | 需要独立 SDK | 上下文亮点 |
|------|------------|-------------|-----------|
| 通义千问 | 完全兼容 | 否 | 1M tokens (turbo/plus) |
| 智谱 GLM | 基本兼容 | zhipuai | 128K |
| 文心 ERNIE | 不兼容 | requests | 2K-8K |
| DeepSeek | 完全兼容 | 否 | 64K |
| Moonshot | 完全兼容 | 否 | 128K |
| 零一万物 | 完全兼容 | 否 | 128K |

**套路总结**：优先选 OpenAI 兼容的 API，这样同一套代码换 `base_url` + `api_key` 就能切换。不兼容的（如百度）需要单独维护调用逻辑。

---

## 选择建议

- 长上下文需求 → 通义千问 (1M) 或 Moonshot
- 推理/逻辑 → DeepSeek Reasoner
- 综合能力 → 通义千问 Qwen-Max 或智谱 GLM-4
- 百度生态 → 文心 ERNIE
- 纯价格敏感 → DeepSeek Chat 或通义千问 Turbo
