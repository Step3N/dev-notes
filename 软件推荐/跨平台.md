# 跨平台推荐软件清单

> 以下软件在 macOS / Windows / Linux 三平台均有良好支持，团队协作或频繁换机用户优先考虑。

## 安装命令速查表

| 软件 | 类别 | macOS（brew） | Windows（winget） | Linux（apt/snap） | 推荐理由 |
|------|------|---------------|-------------------|--------------------|----------|
| **VS Code** | 编辑器 | `brew install --cask visual-studio-code` | `winget install Microsoft.VisualStudioCode` | snap: `sudo snap install code` / apt: 添加微软源 | 插件生态最强，Settings Sync 跨平台同步配置 |
| **Obsidian** | 笔记 | `brew install --cask obsidian` | `winget install Obsidian.Obsidian` | snap: `sudo snap install obsidian` / 官网 AppImage | 本地 Markdown 存储，无厂商锁定 |
| **Git** | 版本控制 | `brew install git` | `winget install Git.Git` | `sudo apt install git` | 三平台行为一致，跨平台协作基础 |
| **Docker** | 容器 | `brew install --cask docker` | `winget install Docker.DockerDesktop` | `curl -fsSL get.docker.com \| sh` | 环境一致性保障，注意 Linux 是 Engine 无 GUI |
| **Firefox** | 浏览器 | `brew install --cask firefox` | `winget install Mozilla.Firefox` | `sudo apt install firefox` | Firefox Sync 跨平台同步书签/密码/标签页 |
| **Chrome** | 浏览器 | `brew install --cask google-chrome` | `winget install Google.Chrome` | 官网下载 .deb / 添加 apt 源 | DevTools 最完善，PWA 支持最好 |
| **1Password** | 密码管理 | `brew install --cask 1password` | `winget install AgileBits.1Password` | 不支持官方 Linux 桌面版（可用浏览器扩展） | 桌面端集成最深入，但不完全跨平台 |
| **Bitwarden** | 密码管理 | `brew install --cask bitwarden` | `winget install Bitwarden.Bitwarden` | snap: `sudo snap install bitwarden` / Flatpak | 开源、全平台、免费，无平台缺失 |
| **Flameshot** | 截图 | `brew install --cask flameshot` | `winget install Flameshot.Flameshot` | `sudo apt install flameshot` | 开源截图标注，三平台覆盖 |
| **Slack** | 通讯 | `brew install --cask slack` | `winget install Slack.Slack` | snap: `sudo snap install slack` | 团队协作标准工具 |
| **Telegram** | 通讯 | `brew install --cask telegram` | `winget install Telegram.TelegramDesktop` | snap: `sudo snap install telegram-desktop` | 全平台原生客户端，API 开放 |
| **Postman** | API 工具 | `brew install --cask postman` | `winget install Postman.Postman` | snap: `sudo snap install postman` | 跨平台 API 调试，集合云端同步 |
| **Insomnia** | API 工具 | `brew install --cask insomnia` | `winget install Insomnia.Insomnia` | snap: `sudo snap install insomnia` | 轻量、支持 GraphQL，同步可选本地 |
| **Rectangle** | 窗口管理 | `brew install --cask rectangle` | → **PowerToys FancyZones** | → **GNOME 自带** | 仅 macOS 需要，Win/Linux 自带类似功能 |
| **DevToys** | 开发者工具 | `brew install --cask devtoys` | `winget install DevToys.DevToys` | 无官方 Linux 版 | macOS/Win 有，Linux 缺，推荐在线工具替代 |

## 跨平台注意事项

### macOS 独占（无 Win/Linux 版）
- **iTerm2** → 替代：Windows Terminal / Linux Kitty
- **Alfred / Raycast** → 替代：PowerToys Run / 系统搜索
- **Bartender / Hidden Bar** → 替代：Windows 任务栏自动隐藏 / Linux 无直接替代
- **Amphetamine** → 替代：系统电源选项设置

### Windows 独占（无 macOS/Linux 版）
- **PowerToys** → 部分功能 macOS 有替代（如 Rectangle 替代 FancyZones）
- **Everything** → 替代：macOS 自带 Spotlight / Linux `locate` 命令
- **AutoHotkey** → 替代：Karabiner-Elements (macOS) / 系统快捷键设置

### Linux 独占（无 Win/macOS 版）
- **tmux** → 替代：iTerm2 分屏 / Windows Terminal 分屏
- **btop / htop** → 替代：macOS Activity Monitor / Windows 任务管理器

## 配置同步建议

```
配置文件统一管理 → 使用 dotfiles 仓库（GitHub）
跨平台包管理器统一:
  macOS: Brewfile
  Windows: winget export
  Linux: apt-mark / 自制安装脚本
```

> 以 **VS Code + Obsidian + Git + 浏览器** 四件套为基础，任何平台都能快速进入工作流。
