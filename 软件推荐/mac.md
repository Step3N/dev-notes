# macOS 开发者必备软件清单

## 开发工具

| 软件 | 说明 | 安装 |
|------|------|------|
| **iTerm2** | 终端模拟器替代品，支持分屏、热键窗口、丰富的配置 | `brew install --cask iterm2` |
| **VS Code** | 轻量级代码编辑器，插件生态最强 | `brew install --cask visual-studio-code` |
| **JetBrains Toolbox** | JetBrains IDE 管理工具，一键安装/更新全家桶 | `brew install --cask jetbrains-toolbox` |
| **Docker Desktop** | 容器化开发环境，本地跑 k8s 集群 | `brew install --cask docker` |
| **TablePlus** | 原生 SQL 客户端，支持 MySQL/PostgreSQL/Redis 等 | `brew install --cask tableplus` |
| **Insomnia** | API 调试工具，支持 GraphQL，界面清爽 | `brew install --cask insomnia` |
| **Warp** | Rust 编写的现代终端，AI 命令搜索、自动补全 | `brew install --cask warp` |
| **OrbStack** | Docker Desktop 的轻量替代，速度快、资源占用低 | `brew install --cask orbstack` |

## 系统工具

| 软件 | 说明 | 安装 |
|------|------|------|
| **AltTab** | 在 macOS 上实现 Windows 风格的窗口切换（显示缩略图） | `brew install --cask alt-tab` |
| **Rectangle** | 窗口快捷分屏管理，快捷键拖动到边缘即可排列 | `brew install --cask rectangle` |
| **Raycast** | Spotlight 替代品，自带计算器、剪贴板历史、插件系统 | `brew install --cask raycast` |
| **Stats** | 菜单栏系统监控：CPU、内存、网络、磁盘、温度 | `brew install --cask stats` |
| **Hidden Bar** | 免费菜单栏图标折叠工具，保持菜单栏整洁 | `brew install --cask hiddenbar` |
| **Amphetamine** | 防止 Mac 自动休眠，可按应用或时间段控制 | `brew install --cask amphetamine` |
| **Maccy** | 轻量剪贴板历史管理器，菜单栏常驻，快捷键呼出 | `brew install --cask maccy` |

## 效率工具

| 软件 | 说明 | 安装 |
|------|------|------|
| **Obsidian** | 本地 Markdown 笔记，双向链接图谱，插件丰富 | `brew install --cask obsidian` |
| **Arc Browser** | 侧边栏标签页浏览器，空间和画布功能独树一帜 | `brew install --cask arc` |
| **Chrome** | 开发者工具最强，PWA 支持完善 | `brew install --cask google-chrome` |
| **1Password** | 密码管理器，浏览器/系统集成最好 | `brew install --cask 1password` |
| **Clop** | 粘贴时自动优化图片体积，支持 WebP/JPEG/PNG | `brew install --cask clop` |
| **Karabiner-Elements** | 键盘改键神器，可映射任意键到任意操作 | `brew install --cask karabiner-elements` |

## 影音娱乐

| 软件 | 说明 | 安装 |
|------|------|------|
| **IINA** | 现代视频播放器，mpv 内核，支持 Touch Bar | `brew install --cask iina` |
| **Spotify** | 流媒体音乐 | `brew install --cask spotify` |
| **Itsycal** | 菜单栏日历增强，快捷查看日程 | `brew install --cask itsycal` |

> 使用 Homebrew 批量安装：`brew install --cask <软件名>`。
> 先安装 Homebrew：`/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"`
