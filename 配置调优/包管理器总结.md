# 包管理器对比总结 — 全平台

跨平台开发者必备：Homebrew / winget / apt / dnf / pacman 一张表搞定。

---

## 📦 适用平台

| 管理器 | 平台 | 包格式 | 首要用途 |
|--------|------|--------|----------|
| **Homebrew** | macOS (也支持 Linux) | `.tar.gz` | macOS 上装 CLI 工具和桌面应用 |
| **winget** | Windows | 无统一格式 | Windows 上装任何软件 |
| **apt** | Debian/Ubuntu 系 | `.deb` | Linux 服务器 / 桌面 |
| **dnf** | Fedora/RHEL 系 | `.rpm` | RHEL 系服务器 / 桌面 |
| **pacman** | Arch 系 | `.pkg.tar.zst` | Arch / Manjaro 桌面 |

---

## ⚙️ 常用操作全对比

| 操作 | Homebrew | winget | apt | dnf | pacman |
|------|----------|--------|-----|-----|--------|
| 安装 | `brew install` | `winget install` | `apt install` | `dnf install` | `pacman -S` |
| 卸载 | `brew uninstall` | `winget uninstall` | `apt remove` | `dnf remove` | `pacman -R` |
| 搜索 | `brew search` | `winget search` | `apt search` | `dnf search` | `pacman -Ss` |
| 升级所有 | `brew upgrade` | `winget upgrade --all` | `apt upgrade` | `dnf upgrade` | `pacman -Syu` |
| 升级单个 | `brew upgrade <包>` | `winget upgrade <包>` | `apt install <包>` | `dnf upgrade <包>` | `pacman -S <包>` |
| 刷新源 | `brew update` | `winget source update` | `apt update` | `dnf check-update` | `pacman -Sy` |
| 列出已装 | `brew list` | `winget list` | `apt list --installed` | `dnf list installed` | `pacman -Q` |
| 查看详情 | `brew info` | `winget show` | `apt show` | `dnf info` | `pacman -Qi` |
| 清理 | `brew cleanup` | ❌ 无内置 | `apt autoremove` | `dnf autoremove` | `pacman -Sc` |
| 导出清单 | `brew bundle dump` | `winget export` | ❌ 无内置 | ❌ 无内置 | ❌ 无内置 |

## 💡 哪个场景用哪个？

### 你在 **macOS** 上开发

- **首选 Homebrew** — 所有 CLI 工具、桌面应用、字体
- 某些 .dmg/.pkg 安装器仍需手动下载（极少）
- `brew bundle` 是换机/重装后的最佳伙伴

### 你在 **Windows** 上开发

- **首选 winget** — 装 VS Code、Git、Node.js、Chrome 等
- 配合 `scoop` 或 `choco` 补足 winget 缺少的包
- 旧版 Windows 可能需要手动升级 App Installer

### 你在 **Linux** 上开发

- **Ubuntu/Debian → apt** — 服务器标配，源最全
- **Fedora/RHEL → dnf** — 企业级，稳定可靠
- **Arch → pacman** — 最激进，滚动更新，AUR 应有尽有

> 多人团队或多平台项目，建议写 `Makefile` 或 `setup.sh` 统一入口，内部判断平台调用对应包管理器。

## 🔧 加速与镜像配置

### Homebrew（macOS）

```bash
# 中科大镜像
export HOMEBREW_BREW_GIT_REMOTE="https://mirrors.ustc.edu.cn/brew.git"
export HOMEBREW_CORE_GIT_REMOTE="https://mirrors.ustc.edu.cn/homebrew-core.git"

# 阿里云
export HOMEBREW_API_DOMAIN="https://mirrors.aliyun.com/homebrew-bottles"
```

### apt（Ubuntu/Debian）

```bash
# 使用清华源
sudo sed -i 's|http://archive.ubuntu.com|https://mirrors.tuna.tsinghua.edu.cn|g' /etc/apt/sources.list
sudo apt update
```

### dnf（Fedora）

```bash
# 使用清华源
sudo sed -e 's|^metalink=|#metalink=|g' \
         -e 's|^#baseurl=http://download.example/pub/fedora/linux|baseurl=https://mirrors.tuna.tsinghua.edu.cn/fedora|g' \
         -i /etc/yum.repos.d/fedora.repo /etc/yum.repos.d/fedora-updates.repo
```

### pacman（Arch）

```bash
# 编辑 /etc/pacman.d/mirrorlist
# 把 China 的 mirrors 放在前面
Server = https://mirrors.tuna.tsinghua.edu.cn/archlinux/$repo/os/$arch
```

### winget（Windows）

winget 源目前不提供第三方镜像，但可以通过配置代理加速：

```powershell
# 如果全局有代理，winget 默认走系统代理
$env:HTTP_PROXY="http://127.0.0.1:7890"
$env:HTTPS_PROXY="http://127.0.0.1:7890"
```

## ⚠️ 通用注意事项

1. **永远不要用 sudo 运行包管理器**（除非它是 apt/dnf/pacman）——`brew` 和 `winget` 不需要 root/admin 提权（winget 安装时会自动请求管理员权限）。
2. **更新源后再安装** — 遇到 "not found" 先刷新源。
3. **避免混合使用** — 在同一系统上不要同时用 apt 和 dnf 管理同一软件。
4. **记录依赖** — 多写 Brewfile / winget export 或 `requirements.txt` 这类清单文件。
5. **只从官方源安装** — 警惕第三方源的供应链风险，AUR 尤其要审查 PKGBUILD。

## 📝 快速参考卡片

```bash
# macOS 新机三连
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew bundle --file=~/Brewfile

# Windows 新机三连
winget import -i packages.json

# Ubuntu 新机三连
sudo apt update && sudo apt upgrade -y
sudo apt install git curl wget build-essential
```
