# apt / dnf / pacman — Linux 三大包管理器速查

各发行版默认包管理器不同，但核心操作大同小异。本文让你在任何一台 Linux 上都能快速上手。

---

## 📦 发行版对应关系

| 管理器 | 发行版 | 包格式 |
|-------|--------|--------|
| `apt` | Debian, Ubuntu, Mint, Kali | `.deb` |
| `dnf` | Fedora, RHEL, CentOS 8+ | `.rpm` |
| `pacman` | Arch Linux, Manjaro, EndeavourOS | `.pkg.tar.zst` |

---

## ⚙️ 命令对照表

### 安装 / 卸载

| 操作 | apt | dnf | pacman |
|------|-----|-----|--------|
| 安装 | `apt install <包>` | `dnf install <包>` | `pacman -S <包>` |
| 卸载（保留配置） | `apt remove <包>` | `dnf remove <包>` | `pacman -R <包>` |
| 卸载（全清除） | `apt purge <包>` | 同 remove | `pacman -Rns <包>` |
| 下载但不装 | `apt download <包>` | `dnf download <包>` | `pacman -Sw <包>` |

### 更新

| 操作 | apt | dnf | pacman |
|------|-----|-----|--------|
| 刷新源 | `apt update` | `dnf check-update` | `pacman -Sy` |
| 升级所有 | `apt upgrade` | `dnf upgrade` | `pacman -Syu` |
| 升级单个 | `apt install <包>` | `dnf upgrade <包>` | `pacman -S <包>` |
| 自动清理 | `apt autoremove` | `dnf autoremove` | `pacman -Sc` |

### 搜索 / 查询

| 操作 | apt | dnf | pacman |
|------|-----|-----|--------|
| 搜索 | `apt search <关键词>` | `dnf search <关键词>` | `pacman -Ss <关键词>` |
| 查看详情 | `apt show <包>` | `dnf info <包>` | `pacman -Qi <包>` |
| 文件属于哪个包 | `dpkg -S <文件>` | `dnf provides <文件>` | `pacman -Qo <文件>` |
| 列出已装 | `apt list --installed` | `dnf list installed` | `pacman -Q` |

> `apt` 和 `apt-get` 的关系：`apt` 是 `apt-get` + `apt-cache` 的精简整合版，日常用 `apt` 就够。

## 🔧 添加第三方源

### apt — PPA

```bash
# 添加 PPA
sudo add-apt-repository ppa:deadsnakes/ppa
sudo apt update
sudo apt install python3.13

# 删除 PPA
sudo add-apt-repository --remove ppa:deadsnakes/ppa
```

### dnf — COPR

```bash
# 启用 COPR 仓库
sudo dnf copr enable user/project

# 从 COPR 安装
sudo dnf install <包>

# 查看已启用的 COPR
dnf copr list
```

### pacman — AUR / 自定义源

Arch 用户通常用 AUR helper（如 `yay`）：

```bash
# 安装 yay
sudo pacman -S --needed git base-devel
git clone https://aur.archlinux.org/yay.git
cd yay && makepkg -si

# 从 AUR 安装软件
yay -S google-chrome
```

编辑 `/etc/pacman.conf` 添加自定义源：

```ini
[archlinuxcn]
Server = https://mirrors.tuna.tsinghua.edu.cn/archlinuxcn/$arch
```

## 💡 实用技巧

### 查找已装包的详细信息

```bash
# apt
apt show vim

# dnf
dnf info vim

# pacman
pacman -Qi vim
```

### 找出哪个包提供了某个命令

```bash
# apt
dpkg -S $(which ffmpeg)

# dnf
dnf provides /usr/bin/ffmpeg

# pacman
pacman -Qo /usr/bin/ffmpeg
```

### 清理无用依赖

```bash
apt autoremove        # Debian/Ubuntu
dnf autoremove        # Fedora
pacman -Qtdq | sudo pacman -Rns -  # Arch
```

## ⚠️ 常见问题

### apt: `Unable to locate package`

```bash
# 先更新源
sudo apt update
# 如果还是没有，检查 universe 源是否开启
sudo add-apt-repository universe
```

### dnf: `No match for argument`

```bash
# 确认是否有正确的仓库启用
dnf repolist
# 或搜索完整名称
dnf search <关键词> --all
```

### pacman: 数据库锁定

```bash
# 删除锁文件
sudo rm /var/lib/pacman/db.lck

# 切勿在有 pacman 进程运行时删除
```
