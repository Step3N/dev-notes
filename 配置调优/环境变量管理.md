# 环境变量管理

> **平台**：全平台

## 基础操作

### macOS / Linux（Bash / Zsh）

```bash
export MY_VAR="hello"       # 设置
echo $MY_VAR                # 查看
printenv                    # 查看所有
env                         # 同上
unset MY_VAR                # 删除
```

### Windows（PowerShell）

```powershell
$env:MY_VAR = "hello"       # 设置
echo $env:MY_VAR            # 查看
Get-ChildItem Env:          # 查看所有
Remove-Item Env:MY_VAR      # 删除
```

### Windows（CMD）

```cmd
set MY_VAR=hello
echo %MY_VAR%
set
set MY_VAR=
```

## 持久化配置

### macOS / Linux

| 文件 | 作用域 |
|------|--------|
| `~/.zshrc` / `~/.bashrc` | 用户级交互 shell — **最常用** |
| `~/.zshenv` | 用户级登录 shell |
| `/etc/environment` | 系统全局 |
| `/etc/profile` | 系统级登录 shell |

```bash
echo 'export EDITOR="vim"' >> ~/.zshrc
source ~/.zshrc
```

### Windows（PowerShell）

```powershell
# 用户级（持久化）
[Environment]::SetEnvironmentVariable("MY_VAR", "hello", "User")

# 系统级（管理员）
[Environment]::SetEnvironmentVariable("MY_VAR", "hello", "Machine")

# 或写入 $PROFILE
notepad $PROFILE
```

### Windows（CMD → setx）

```cmd
setx MY_VAR "hello"     # 用户级
setx MY_VAR "hello" /M  # 系统级
```

## PATH 管理

### macOS / Linux

```bash
echo $PATH                # 查看（冒号分隔）
echo $PATH | tr ':' '\n'  # 分行查看

# 添加到 ~/.zshrc
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
echo 'export PATH="$HOME/.cargo/bin:$PATH"' >> ~/.zshrc
```

### Windows（PowerShell）

```powershell
$env:PATH -split ';'      # 查看（分号分隔）

# 永久添加
$oldPath = [Environment]::GetEnvironmentVariable("Path", "User")
$newPath = "$oldPath;C:\Tools\bin"
[Environment]::SetEnvironmentVariable("Path", $newPath, "User")
```

## direnv — 目录级环境变量

```bash
brew install direnv                      # macOS
sudo apt install direnv                  # Debian/Ubuntu
echo 'eval "$(direnv hook zsh)"' >> ~/.zshrc  # 配置
source ~/.zshrc
```

```bash
# 在项目目录创建 .envrc
cd my-project
echo 'export API_KEY="sk-xxx"' > .envrc
direnv allow             # 首次需要授权

cd ..                    # 自动卸载
echo $API_KEY            # 空
```

## .env 文件（dotenv）

```bash
# .env 文件格式（无引号包裹值）
DATABASE_URL=postgres://localhost:5432/mydb
API_KEY=sk-abc123
NODE_ENV=development
```

谁来加载：Node.js（`dotenv` 包）、Python（`python-dotenv`）、Docker Compose（`env_file`）。Shell 不会自动加载：

```bash
# Shell 手动加载
export $(grep -v '^#' .env | xargs)
```

## 安全实践

```bash
# .gitignore 中排除 .env
echo ".env" >> .gitignore
echo ".envrc" >> .gitignore

# 提交 .env.example（仅键名，无值）
echo "DATABASE_URL=" > .env.example
echo "API_KEY=" >> .env.example

# 防止 API Key 进 shell 历史（命令前加空格）
 export SECRET="abc123"
```

## 常见变量

```bash
export EDITOR="vim"                     # 默认编辑器
export LANG="zh_CN.UTF-8"              # 语言编码
export HTTP_PROXY="http://127.0.0.1:7890"   # 代理
export GOPATH="$HOME/go"               # Go
export CARGO_HOME="$HOME/.cargo"       # Rust
export NODE_ENV="development"          # Node.js
```

## 验证

```bash
env | wc -l                            # 环境变量数量
echo ${MY_VAR:-"未设置"}                # 检查是否存在（提供默认值）
echo $PATH | tr ':' '\n' | grep brew   # 检查 PATH 中是否有 brew
```
