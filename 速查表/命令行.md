# 命令行速查表

> macOS / Linux · 常用命令速查 · ⚠️ 标注了 macOS 与 GNU 差异

## 文件操作 File Operations

| 命令 | 说明 |
|------|------|
| `ls` | 列出文件 |
| `ls -la` | 列出所有文件（含隐藏）+ 详情 |
| `ls -lhS` | 按大小排序，人性化显示 |
| `ls -1` | 每行一个文件 |
| `cp <src> <dst>` | 复制文件 |
| `cp -r <src> <dst>` | 递归复制目录 |
| `cp -i <src> <dst>` | 覆盖前确认 |
| `mv <src> <dst>` | 移动/重命名 |
| `mv -i <src> <dst>` | 覆盖前确认 |
| `rm <file>` | 删除文件 |
| `rm -r <dir>` | 递归删除目录 |
| `rm -rf <dir>` | 强制删除（慎用！） |
| `rm -i <file>` | 逐个确认删除 |
| `mkdir -p a/b/c` | 创建多级目录 |
| `touch <file>` | 创建空文件 / 更新时间戳 |

## 文件内容 File Content

| 命令 | 说明 |
|------|------|
| `cat <file>` | 查看文件内容 |
| `cat -n <file>` | 显示行号 |
| `less <file>` | 分页查看（`/`搜索 `q`退出） |
| `head -n 20 <file>` | 查看前 20 行 |
| `tail -n 20 <file>` | 查看后 20 行 |
| `tail -f <file>` | 实时跟踪文件追加内容 |
| `grep <pattern> <file>` | 搜索文本 |
| `grep -i <pattern> <file>` | 忽略大小写 |
| `grep -r <pattern> <dir>` | 递归搜索目录 |
| `grep -n <pattern> <file>` | 显示行号 |
| `grep -l <pattern> <dir>/*` | 只显示匹配的文件名 |
| `wc <file>` | 统计行/词/字符 |
| `wc -l <file>` | 只统计行数 |
| `sort <file>` | 排序 |
| `sort -n -k2 <file>` | 按数字排序第 2 列 |
| `uniq <file>` | 去重（需先 sort） |

## 权限 Permissions

| 命令 | 说明 |
|------|------|
| `chmod 755 <file>` | 设置权限 rwxr-xr-x |
| `chmod +x <file>` | 添加可执行权限 |
| `chmod -R 755 <dir>` | 递归设置目录权限 |
| `chown user:group <file>` | 更改所有者/组 |
| `chown -R user <dir>` | 递归更改所有者 |
| `umask 022` | 设置默认权限掩码 |

## 进程 Process

| 命令 | 说明 |
|------|------|
| `ps aux` | 查看所有进程 |
| `ps aux | grep nginx` | 搜索特定进程 |
| `ps -ef` | 查看完整进程列表 |
| `top` | 实时进程监控（按 q 退出） |
| `htop` | 增强版 top（需安装） |
| `kill <pid>` | 终止进程 |
| `kill -9 <pid>` | 强制杀死进程 |
| `kill -15 <pid>` | 优雅终止 |
| `pkill <name>` | 按名称杀进程 |

## 网络 Network

| 命令 | 说明 |
|------|------|
| `ping -c 4 <host>` | ICMP 连通性测试 |
| `curl <url>` | HTTP 请求（默认输出 body） |
| `curl -I <url>` | 只获取响应头 |
| `curl -o <file> <url>` | 下载文件 |
| `curl -H "K: v" <url>` | 自定义请求头 |
| `curl -X POST -d 'key=val' <url>` | POST 请求 |
| `wget <url>` | 下载文件 |
| `wget -c <url>` | 断点续传 |
| `ss -tlnp` | 查看监听端口（Linux） |
| `lsof -i :8080` | 查看占用 8080 端口的进程（macOS/Linux） |
| `netstat -an` | 查看所有网络连接 |

## 压缩 Compression

| 命令 | 说明 |
|------|------|
| `tar -czf <out>.tar.gz <dir>` | 创建 tar.gz 压缩包 |
| `tar -xzf <file>.tar.gz` | 解压 tar.gz |
| `tar -cjf <out>.tar.bz2 <dir>` | 创建 tar.bz2（更小更慢） |
| `tar -xjf <file>.tar.bz2` | 解压 tar.bz2 |
| `tar -xf <file>.tar` | 解压 tar（无压缩） |
| `gzip <file>` | 压缩文件（原文件替换为 .gz） |
| `gunzip <file>.gz` | 解压 gz |
| `zip -r <out>.zip <dir>` | 压缩为 zip |
| `unzip <file>.zip` | 解压 zip |

## 磁盘 Disk

| 命令 | 说明 |
|------|------|
| `df -h` | 磁盘分区使用情况（人性化显示） |
| `du -sh <dir>` | 统计目录总大小 |

## ⚠️ macOS vs Linux 差异

| 场景 | macOS | Linux |
|------|-------|-------|
| `sed -i` 原地编辑 | `sed -i '' 's/old/new/g' file` | `sed -i 's/old/new/g' file` |
| `date` 格式化 | `date -j -f "%Y-%m-%d" "2024-01-01" +%s` | `date -d "2024-01-01" +%s` |
| `readlink -f` | 不内置，可用 `realpath` 或 `brew install coreutils` | 支持 |
| `top` 退出键 | `q` 或 `Ctrl-c` | `q` |
| `lsof` | 默认可用 | 需安装 `lsof` |
| `ss` | 不可用，用 `netstat` | 可用 |
| `wc -l` 换行符 | macOS 旧版可能差异 | 标准 |
| 多核 `xargs` | `-P` 支持 | `-P` 支持 |
| 剪贴板 | `pbcopy` / `pbpaste` | `xclip` / `xsel`（需安装） |
| 显存/系统信息 | `system_profiler` | `lspci` / `lsusb` |
