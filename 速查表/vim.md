# Vim 速查表

> 全平台通用 · 常用操作速查 · 模式：`正常(N) 插入(I) 可视(V) 命令(C)`

## 导航 Navigation（N 模式）

| 命令 | 说明 |
|------|------|
| `h` `j` `k` `l` | ← ↓ ↑ → 移动光标 |
| `w` `b` | 按词前进 / 后退 |
| `e` | 跳到词尾 |
| `0` `^` `$` | 行首 / 行首非空 / 行尾 |
| `gg` `G` | 文件首 / 文件尾 |
| `<n>gg` `<n>G` | 跳转到第 n 行 |
| `Ctrl-d` `Ctrl-u` | 向下 / 向上翻半页 |
| `Ctrl-f` `Ctrl-b` | 向下 / 向上翻一页 |
| `%` | 跳转到匹配括号 |
| `{` `}` | 按段落上 / 下跳转 |
| `zz` `zt` `zb` | 当前行居中 / 置顶 / 置底 |
| `gd` `gf` | 跳转到定义 / 文件（光标下路径） |

## 编辑 Editing（N → I 模式）

| 命令 | 说明 |
|------|------|
| `i` `a` | 光标前插入 / 后插入 |
| `I` `A` | 行首插入 / 行尾插入 |
| `o` `O` | 下方新行插入 / 上方新行插入 |
| `dd` `yy` | 剪切 / 复制当前行 |
| `<n>dd` `<n>yy` | 剪切 / 复制 n 行 |
| `p` `P` | 粘贴到下方 / 上方 |
| `x` `X` | 删除光标处字符 / 删除光标前字符 |
| `dw` `diw` | 删除一个词 / 删除光标所在词 |
| `d$` `d0` | 删除到行尾 / 行首 |
| `D` | 等价于 `d$` |
| `c<move>` | 修改（删除并进入插入模式） |
| `cc` `C` | 修改整行 / 从光标到行尾 |
| `r<x>` | 替换当前字符为 x |
| `R` | 进入替换模式（覆盖字符） |
| `u` `Ctrl-r` | 撤销 / 重做 |
| `.` | 重复上次修改 |

## 可视模式 Visual Mode（N → V 模式）

| 命令 | 说明 |
|------|------|
| `v` | 进入字符可视模式 |
| `V` | 进入行可视模式 |
| `Ctrl-v` | 进入块可视模式 |
| `y` `d` | 复制 / 剪切选中内容 |
| `~` `u` `U` | 切换大小写 / 小写 / 大写 |
| `>` `<` | 向右 / 向左缩进 |
| `J` | 合并选中行 |
| `g Ctrl-a` | 递增选中数字序列 |

## 搜索与替换 Search & Replace

| 命令 | 说明 |
|------|------|
| `/pattern` | 向下搜索 pattern |
| `?pattern` | 向上搜索 pattern |
| `n` `N` | 下一个匹配 / 上一个匹配 |
| `*` `#` | 向下 / 向上搜索光标处词 |
| `:s/old/new` | 替换当前行第一个 |
| `:s/old/new/g` | 替换当前行全部 |
| `:%s/old/new/g` | 替换全文 |
| `:%s/old/new/gc` | 替换全文，逐个确认 |
| `:<n>,<m>s/old/new/g` | 替换 n~m 行 |

## 窗口与标签 Windows & Tabs

| 命令 | 说明 |
|------|------|
| `:sp <file>` | 水平分割窗口 |
| `:vsp <file>` | 垂直分割窗口 |
| `Ctrl-w h/j/k/l` | 焦点移动到左/下/上/右窗口 |
| `Ctrl-w w` | 循环切换窗口 |
| `Ctrl-w =` `Ctrl-w _` `Ctrl-w \|` | 等分 / 最大化高 / 最大化宽 |
| `:tabnew <file>` | 新建标签页 |
| `gt` `gT` | 下一个 / 上一个标签页 |
| `<n>gt` | 跳转到第 n 个标签页 |

## 保存与退出 Saving & Quitting

| 命令 | 说明 |
|------|------|
| `:w` | 保存 |
| `:w <file>` | 另存为 |
| `:q` | 退出（未保存则拒绝） |
| `:q!` | 强制退出（不保存） |
| `:wq` `ZZ` | 保存并退出 |
| `:wq!` | 强制保存并退出 |
| `:x` | 保存并退出（仅修改时写入） |
| `:e!` | 重新加载文件（丢弃修改） |
| `:cq` | 强制退出并返回非零状态码 |
| `ZQ` | 不保存退出 |

## 插入模式特殊操作 Insert Mode Specials

| 命令 | 说明 |
|------|------|
| `Ctrl-h` | 删除前一个字符 |
| `Ctrl-w` | 删除前一个词 |
| `Ctrl-u` | 删除到行首 |
| `Ctrl-p` `Ctrl-n` | 自动补全（上/下） |
| `Ctrl-t` `Ctrl-d` | 向右 / 向左缩进 |
| `Ctrl-x Ctrl-f` | 文件路径补全 |
| `Ctrl-o <cmd>` | 临时执行一个正常模式命令 |
| `Ctrl-r =` | 插入表达式计算结果（如 `4+5`） |
| `Ctrl-v <key>` | 插入特殊字符 |
