# Markdown 语法速查表

> 平台：全平台

## 标题

| 语法 | 渲染效果 |
|------|----------|
| `# H1` | H1（最大） |
| `## H2` | H2 |
| `### H3` | H3 |
| `###### H6` | H6（最小） |

## 粗体 / 斜体

| 语法 | 渲染效果 |
|------|----------|
| `*斜体*` or `_斜体_` | *斜体* |
| `**粗体**` | **粗体** |
| `***粗斜体***` | ***粗斜体*** |
| `~~删除线~~` | ~~删除线~~ |

## 列表

| 语法 | 说明 |
|------|------|
| `- item` or `* item` | 无序列表 |
| `1. item` | 有序列表（自动编号） |
| `- [ ] task` | 未完成任务 |
| `- [x] task` | 已完成任务 |

```markdown
- 无序
- 列表

1. 有序
2. 列表

- [x] 完成
- [ ] 待办
```

## 链接

| 语法 | 说明 |
|------|------|
| `[文本](https://example.com)` | 普通链接 |
| `[文本](url "标题")` | 带悬停提示 |
| `<https://auto.link>` | 自动链接 |
| `[ref]: https://example.com` | 引用式链接（文末定义） |

## 图片

| 语法 | 说明 |
|------|------|
| `![alt](url)` | 行内图片 |
| `![alt](url "标题")` | 带提示图片 |

## 代码

| 语法 | 说明 |
|------|------|
| `` `code` `` | 行内代码 |
| ```` ```lang ```` | 围栏式代码块（标注语言） |

```python
def hello():
    print("Hello World")
```

## 引用

| `> > nested` | 嵌套引用 |
